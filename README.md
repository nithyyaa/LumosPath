# LumosPath  
Illuminate Your Way Home Safely

## Description
LumosPath is an AI-powered safety navigation system designed to guide users through the safest routes instead of the shortest. It analyzes real-time lighting conditions, crowd density, crime history, and emergency proximity to help users travel safely, especially during nighttime or in unfamiliar areas.

## Key Features
- Safety-first route navigation
- Real-time safety index for streets
- Analysis of lighting, crowd density, and crime data
- Emergency proximity awareness (police, hospitals)
- Designed for women, students, and night commuters

## Tech Stack
- Frontend: Flutter, Mapbox SDK  
- Backend: Node.js, FastAPI  
- AI/ML: TensorFlow, OpenCV, NLP models  
- Database: PostgreSQL, Firebase  
- Cloud: AWS

## Project Status
This project is currently in the prototype and architectural design stage. The repository contains design logic, concept implementation, and system architecture developed as part of a hackathon/academic project.
